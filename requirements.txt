# Runtime dependencies for local (conda) and server (Docker) installs alike.
# pyproject.toml stays the single source of truth for version constraints —
# this just selects which of its extras to install, so there is nothing here
# to fall out of sync when a dependency's version bound changes.
#
# cli     — the `click`-based CLI twin of the always-installed argparse one
# dataviz — the data-side tier behind the generators, causal inference
#           and explainability (tables, geometry, models; nothing draws)
# studio  — the NiceGUI app (chat-driven figure editing, Ralph eyeball loop)
# api     — the FastAPI app; the container's default command serves it, and
#           without this the image could not run its own CMD
# mcp     — the same routes republished as agent tools
-e .[cli,dataviz,studio,api,mcp]

# Heavier, narrow extras — opt in by uncommenting, not installed by default:
# -e .[causal]   # make_causal_estimate.py (dowhy, econml)
# -e .[explain]  # explain_model.py (shap, shapash)
# -e .[local]    # ralph_eyeball_loop.py --local (offline VLM critique)
